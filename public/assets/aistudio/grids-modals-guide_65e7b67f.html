Reading the Kigali Fleet car card

Problems seen in your screenshot, in order of how much they hurt:

  • Cut-off text. “Safety Che… Expires in …” hides the one fact the owner needs. Never truncate status text; let it wrap or shorten the label.
  • Unreadable color pairs. Amber text on brown, pink on magenta, mint on teal. Each fails contrast. Use dark text on a pale tint, or white on a deep color.
  • Boxes inside boxes. Card, then driver box, then badges, then rate box, then warning box. Five frames around eight facts. Whitespace and one hairline do the same job.
  • Big radius everywhere. Pills, cards and inner boxes all round at once, so nothing feels more important.
  • Label/value split by distance. “Main Driver:” sits far left and the name far right. The eye must travel across empty space.
  • Too many actions. Repair, Details, Book, Edit Rate and an arrow icon on one card. Pick one primary action (Book); put the rest behind Details.

About the Alanii Autos dashboard you sent: its strengths are the big page title, generous spacing, one typeface and a clear sidebar. It still uses outlined rounded cards and tracked capital labels, so it is cleaner, not fully flat. Treat it as a good middle step.

Modals

A modal blocks everything behind it, so use one only when the person must decide or enter something before continuing. Open each type below.

Do

  • Name the action in the title: “Delete this car?”
  • Button labels repeat the verb: “Delete car”, not “OK”.
  • Put the main action on the right, and make destructive actions red.
  • Close with Esc, the Cancel button, and a click outside.
  • Use a drawer for long forms so the page stays visible.

Don’t

  • Open a modal from a modal.
  • Use one for information that could sit on the page.
  • Add a large radius, thick border and gradient; a plain surface looks sharper.
  • Write “Are you sure?” with no detail.
  • Hide the close control or trap keyboard focus.
